# Improvement and Retake

## Retake (failed courses)
If you fail a course you must retake it. Failed courses appear on the Retake page of the portal, where you can request to register for them again.
A retake request has a status: Pending, Approved or Rejected.

## Improvement
A student who passed a course but wants a better grade can apply for improvement. Improvement is allowed only for courses with grade C or lower.
Apply from the Improvement page of the portal. The request status is Pending until the department reviews it.
The new grade replaces the old grade in the CGPA calculation.
A maximum of 4 improvement courses are allowed during the whole degree.
